# Documentos históricos en archive/

Los siguientes documentos están en `archive/reports_v3/` como referencia de iteraciones
anteriores del desarrollo:

- `v3_validation_summary.md`: snapshot de validación del experimento v3 (11.500 interacciones,
  generador sin timestamp por usuario, sin split por pares).
- `v3_resumen_actual.md`: estado del proyecto al cierre de v3.
- `v3_correcciones_pdf.md`: lista de correcciones aplicadas durante v3 → v6.

Para el experimento actual (v6), consultar:
- `docs/informe_detallado_evaluacion.md` para el detalle metodológico.
- `docs/plan_evaluacion_modelos.md` para el plan experimental.
- `evaluation_metrics_warm.csv` y `evaluation_metrics_cold.csv` para los resultados.
